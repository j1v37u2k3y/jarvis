# --- Voice recognition (resemblyzer) ---------------------------------------
# Resemblyzer pulls librosa → numba → llvmlite → torch. On macOS x86_64 +
# Python 3.12, the latest llvmlite has no wheel (tries to compile against
# LLVM from source). Pinning to the last versions that ship prebuilt wheels
# for this platform. torch 2.2.2 was compiled against numpy 1.x ABI, so
# numpy<2 is required. webrtcvad (resemblyzer dep) uses the deprecated
# pkg_resources API that setuptools>=81 removed, so setuptools<80.
#
# torch: PyTorch stopped shipping x86_64 macOS wheels after 2.2.2.
# CVE fixes (2.5+, 2.6+, 2.7.1+, 2.8+) are Linux/ARM-only on macOS.
# Linux CI and Linux deploys pull >=2.7.1 (CVE-free). macOS x86_64 dev
# workstations stay on 2.2.2 — documented known CVEs affect dev boxes
# only, no production surface on x86_64 macOS.
torch>=2.7.1; platform_system != "Darwin" or platform_machine != "x86_64"
